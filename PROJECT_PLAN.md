# UrbanPulse – NYC 311 Service Request Analysis

## 1. Project Objective
To analyze 100,000 NYC 311 service requests and identify complaint patterns, borough-wise distribution, agency workload, and resolution performance.

## 2. Project Workflow
1. Problem Statement
2. Data Collection
3. Data Cleaning and Preprocessing
4. Data Quality Assessment
5. Exploratory Data Analysis (EDA)
6. Statistical Analysis
7. MySQL Database Integration
8. SQL-Based Data Investigation
9. Interactive Streamlit Dashboard
10. Business Insights and Reporting

## 3. Dataset
- Source: NYC 311 Service Requests
- Records: 100,000
- Raw dataset: raw_311_data.csv
- Cleaned dataset: cleaned_311_data.csv

## 4. Development Environment
- Python
- Visual Studio Code
- MySQL
- Pandas
- NumPy
- Requests
- PyMySQL
- SQLAlchemy
- Matplotlib
- Seaborn
- Streamlit

## 5. Project Deliverables
- Data extraction and cleaning scripts
- Eight EDA visualizations
- MySQL database integration
- Twelve SQL analyst investigations
- Interactive Streamlit dashboard
- Project documentation

## 6. Expected Outcome
An interactive NYC 311 analytics solution that helps identify complaint trends, geographic patterns, and service resolution performance.
